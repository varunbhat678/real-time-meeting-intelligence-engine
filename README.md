
# Real-Time Meeting Intelligence Engine

A web-based meeting application with an AI layer for meeting summarization, action-item extraction, and key-topic identification.

## Planned Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: PostgreSQL, SQLAlchemy
- Authentication: JWT
- Real-time communication: WebSockets and WebRTC
- Speech-to-text: Whisper or faster-whisper
- AI: Fine-tuned pretrained language model
